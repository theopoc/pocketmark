# Embedded font

Figtree variable font (weights 300 to 900), SIL Open Font License 1.1, license text in `OFL.txt`.

- Source: the `@fontsource-variable/figtree` npm package, version 5.3.0 (`files/figtree-latin-wght-normal.woff2`, `files/figtree-latin-ext-wght-normal.woff2` and `files/figtree-latin-wght-italic.woff2`), which republishes the official Google Fonts build.
- The files are copied unchanged and renamed. Update them by downloading a newer package version into an empty directory, comparing the files and refreshing the hashes below.
