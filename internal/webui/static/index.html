      Backup & restore
      A full backup keeps your bookmarks, captures, attachments, highlights and account settings together.
      Download full backup
      How to restore a backup
      1. Stop Pocketmark before restoring.
      2. Unzip the backup and follow its RESTORE instructions. Use an empty data directory and keep your server-secret (or legacy access-token / POCKETMARK_TOKEN) separately.
      3. Restore file ownership if needed, then restart Pocketmark.
      JSON and browser HTML exports contain bookmark metadata, not captures or attached files.
      Password sign-in
      At least 12 characters.
      Browser bookmark sync
      In Floccus, add a WebDAV account using this server’s address with /dav/ appended and the file bookmarks.xbel. Use any username with a dedicated API key as the password. Choose the Floccus sync permissions when creating a key in API keys.
      Sync includes bookmarks and collection folders. Uploading a Floccus file replaces the synchronized bookmark tree; deletions in that file remove matching bookmarks.
      Mobile & browser
      Install this page from your browser’s menu to use Pocketmark as a mobile app. Share a link to it where your browser supports web share targets. The companion extension saves the current page, its rendered HTML, or a screenshot.

          Bookmarks, collections & tags
          
        
            
        1. Choose Add bookmark and paste a URL.
        2. Pick a collection, or leave it in Inbox.
        3. In Tags, choose an existing tag or type a new name and press Enter.
        
            
        Browse your full index in Tags. To edit several bookmarks at once, select their checkboxes, then choose Actions.
        
          
        
        
        
        
        
          Search & filters
          
        
            
        Search covers titles, URLs, descriptions, notes, tags and captured text. A highlighted excerpt shows the match.
        
            
        Search automatically includes similar words in bookmark titles, URLs, descriptions and tags, alongside full-text matches in notes and captured text.
        
            
        Clear the active chips to remove filters.
        
          
        
        
        
        
        
          Reading, highlights & notes
          
        
            
        Open a bookmark’s title to see its saved HTML, screenshots and PDFs. Choose a format to open the latest copy and use the file selector for earlier copies. To read extracted text, choose Reading options → Text & highlights. Reading options also contains text size, formatted view and capture controls.
        
            
        • Select a passage, then choose Highlight.
        • Use Notes in the reader toolbar to write and save your notes.
        
          
        
        
        
        
        
          Failed or missing captures
          
        
            
        1. Open the bookmark to check its capture status and reason.
        2. If it failed, choose Retry capture. You can also use Reading options → Refresh capture.
        3. If the site requires signing in or blocks capture, use Visit original, then attach an HTML snapshot or PDF under Files.
        
            
        Text-only captures cannot provide a formatted page.
        
          
        
        
        
        
        
          Unsaved drafts
          
        
            
        Unsaved bookmark edits, notes and annotations stay in this tab when you close a dialog. They also survive a reload when browser storage is available. A warning appears before leaving with unsaved work.
        
            
        Save before closing the tab or signing out. Discard draft removes only your unsaved changes.
        
          
        
        
        
        
        
          Backup & restore
          
        
            
        Settings → Backup & restore downloads the full library, captures, files and account settings. Keep the ZIP private.
        
            
        1. Stop Pocketmark.
        2. Restore into an empty data directory, following the included RESTORE.txt instructions.
        3. Restart Pocketmark.
        
            
        Keep your server-secret (or legacy access-token / POCKETMARK_TOKEN) separately. JSON and HTML exports contain bookmark metadata only.
        
          
        
        
        
        
        
          Extensions & browser sync
          
        
            
        Create a dedicated key under Settings → API keys for each extension or sync app. Choose Add, edit & capture for the Pocketmark extension, or Floccus sync for Floccus. Browser sign-in uses your password and an authentication or recovery code.
        
            
        Settings contains Floccus WebDAV instructions and mobile installation guidance.
        
            
        Floccus uploads replace the synchronized bookmark tree. Review sync settings before uploading.
