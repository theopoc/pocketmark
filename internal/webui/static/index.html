    Backup & restore

    A full backup keeps your bookmarks, captures, attachments, highlights and account settings together.

    Download full backup
    How to restore a backup
    1. Stop Pocketmark before restoring.
    2. Unzip the backup and follow its RESTORE instructions. Use an empty data directory and keep your existing access-token file or POCKETMARK_TOKEN separately.
    3. Restore file ownership if needed, then restart Pocketmark.

    JSON and browser HTML exports contain bookmark metadata, not captures or attached files.

    Password sign-in

    At least 12 characters.

    Browser bookmark sync

    In Floccus, add a WebDAV account using this server’s address with /dav/ appended and the file bookmarks.xbel. Use any username with a dedicated API key as the password. Create a key from API keys in the navigation.

    Sync includes bookmarks and collection folders. Uploading a Floccus file replaces the synchronized bookmark tree; deletions in that file remove matching bookmarks.

    Mobile & browser

    Install this page from your browser’s menu to use Pocketmark as a mobile app. Share a link to it where your browser supports web share targets. The companion extension saves the current page, its rendered HTML, or a screenshot.

    Export bookmarks

    Choose a portable format. Saved files and captures are stored in your data directory and are not included in these metadata exports.

    To keep captures, files and account settings, download a full backup instead. Restore instructions are included.

    Help

    Find a saved page

    Search looks through titles, URLs, descriptions, notes, tags and captured text. A highlighted excerpt shows the match. In View options, Include near matches also finds similar words in bookmark metadata; it does not search captured text. Clear the active chips to remove filters.

    Save and organize bookmarks

    Choose Add bookmark and paste a URL. Pick a collection, or leave it in Inbox. In Tags, choose an existing tag or type a new name and press Enter. Use All tags to browse your full index. Select bookmark checkboxes, then Actions, to update several at once.

    Read, highlight and add notes

    Open a bookmark’s title to read its saved text. Reading options contains text size, formatted view, printing and capture controls. Select a passage before choosing Highlight. Use the Notes shortcut at the top of the reader to write and save your notes.

    Recover a failed or missing capture

    Open the bookmark to see the capture status and reason. In Reading options, choose Refresh capture. If a site requires signing in or blocks capture, use Visit original, then attach an HTML snapshot or PDF under Files. Text-only captures cannot provide a formatted page.

    Keep and recover a draft

    Unsaved bookmark edits, notes and annotations remain in this tab when you close a dialog. When browser storage is available, they also survive a reload. A warning appears before leaving with unsaved work. Save before closing the tab or signing out; Discard draft removes only your unsaved changes.

    Back up and restore your library

    Settings → Backup & restore downloads the full library, captures, files and account settings. Keep the ZIP private. Stop Pocketmark, restore into an empty data directory using the included RESTORE.txt instructions, then restart. Keep your access-token file or POCKETMARK_TOKEN separately. JSON and HTML exports contain bookmark metadata only.

    Use keyboard shortcuts

    Press / to search or N to add a bookmark, except while typing in a field. Press Escape to close a dialog; unsaved edits remain as a draft. Use Tab and Shift+Tab to move between controls, then Enter or Space to activate them.

    Connect an extension or sync app

    Create a dedicated key under API keys for each extension or sync app. Browser sign-in uses your username and password. Settings contains Floccus WebDAV instructions and mobile installation guidance. Floccus uploads replace the synchronized bookmark tree, so review sync settings before uploading.
